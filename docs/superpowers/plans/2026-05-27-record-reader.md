# RecordReader v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a lightweight Chinese SwiftUI iPhone recording player with folder selection, playback, favorites, categories, Chinese subtitle recognition status, and cloud compilation.

**Architecture:** Put scan, metadata, and subtitle domain rules in `RecordReaderCore` so they can be tested with Swift Package Manager. Put Chinese SwiftUI copy, file picker, AVFoundation playback, and `zh_CN` Speech framework integration in the iOS app target generated by XcodeGen.

**Tech Stack:** Swift 5.9, SwiftUI, AVFoundation, Speech (`zh_CN` only), UniformTypeIdentifiers, Swift Package Manager, XcodeGen, GitHub Actions.

---

## File Structure

- `Package.swift`: Swift package manifest for `RecordReaderCore` and unit tests.
- `Sources/RecordReaderCore/Recording.swift`: recording value model and stable recording key.
- `Sources/RecordReaderCore/RecordingLibraryMetadata.swift`: metadata, subtitle status, and subtitle segment models.
- `Sources/RecordReaderCore/RecordingLibraryScanner.swift`: fail-fast folder scanning and audio extension filtering.
- `Sources/RecordReaderCore/RecordingMetadataStore.swift`: JSON load/save for metadata.
- `Tests/RecordReaderCoreTests/RecordingLibraryScannerTests.swift`: scanner behavior tests.
- `Tests/RecordReaderCoreTests/RecordingMetadataStoreTests.swift`: metadata persistence tests.
- `App/RecordReader/RecordReaderApp.swift`: app entry point.
- `App/RecordReader/ContentView.swift`: dark player-first SwiftUI screen.
- `App/RecordReader/RecordingLibrarySheet.swift`: recording list and filters.
- `App/RecordReader/SubtitlePanel.swift`: subtitle display and recognition status.
- `App/RecordReader/AudioLibraryViewModel.swift`: UI state, folder restore, scan, metadata mutations, transcription orchestration.
- `App/RecordReader/PlayerController.swift`: AVAudioPlayer wrapper.
- `App/RecordReader/SpeechTranscriber.swift`: iOS Speech framework adapter.
- `project.yml`: XcodeGen project definition.
- `.github/workflows/ios.yml`: cloud test/build pipeline.
- `docs/superpowers/milestones.md`: checkpoint log.
